# Docs Template

The maintained source for this built-in template is:

```text
packages/api/templates/docs-template.md
```

Backlogger loads that file at API startup and exposes it as the `docs-template`
template in the New Document dialog. Keep template wording, placeholders, and
examples in the built-in template file so app-created documents and maintained
template content do not drift.

This note exists only so the docs project can point to the source of truth.
