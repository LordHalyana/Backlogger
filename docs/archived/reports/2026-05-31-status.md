## What's shipped (cumulative, end of P2)

- **Storage:** atomic Markdown writes under `data/projects/<id>/`, FK-cascading SQLite tables, startup auto-reindex, safe path resolver.
- **Editor:** CodeMirror 6 + `oneDark`, debounced save (800 ms) with `If-Match` optimistic locking, 409 conflict banner, `beforeunload` guard, modal-based dialogs + toasts, Edit/Split/Preview toggle, lazy-loaded editor chunk.
- **Documents & types:** zod frontmatter schema, `<slug>-<short8>.md` naming, type-aware New-Document dialog.
- **Templates:** 5 built-ins + user templates from `data/templates/`, precedence + collision warning, hot reload via Settings.
- **Search:** FTS5 `documents_fts`, prefix-AND semantics, command palette (Ctrl/Cmd+K). Bench: **p95 = 4.57 ms** (budget 100 ms).
- **Linking:** `[[wiki-link]]` parser, autocomplete, `links` table maintained transactionally, backlinks panel, rename re-resolution.
- **Tags:** kebab-case normalization, `tags` + `document_tags`, sidebar TagExplorer, AND-filtered document tree, chip-based input in MetadataPanel.
- **Hardening:** Playwright e2e in CI, perf bench, bundle audit, dark theme default, error boundary.

## Known caveats / debt
