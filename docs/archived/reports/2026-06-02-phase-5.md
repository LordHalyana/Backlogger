| `KnowledgeGraph` canvas component | `packages/web/src/components/KnowledgeGraph.tsx` |
| Topbar "Graph" button + overlay routing | `packages/web/src/App.tsx` |

**Key design decisions:**
- `react-force-graph-2d` (canvas, MIT, ~30 kB gzip) chosen over SVG and WebGL alternatives.
- 8-entry LRU cache with 10 s TTL; cache invalidated on every document mutation.
- Broken-link sink nodes (`kind: 'broken'`) rendered in accent-red; orphan nodes in muted slate.
- Node size scales with in-degree (range 3–14 px radius).
