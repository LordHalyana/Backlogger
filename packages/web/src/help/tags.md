# Tags

Tags live in the document's frontmatter:

```markdown
---
id: 7c1a…
title: Sprint Notes
tags: [sprint, retro, q3]
---

# Sprint Notes
…
```

## Filtering by tag

The **Tags** panel in the left sidebar lists every tag used in the current
project. Click a tag to filter the document tree; click another to AND it
with the first. Use the small **×** chips to remove a filter.

## Naming conventions

- Lowercase, hyphenated (`design-review`, not `Design Review`).
- No leading `#`.
- Plural or singular — pick one and be consistent inside a project.

## What tags are *not*

- They are **not** folders. A document can have any number of tags.
- They are **not** searched as free text; use the **Search** chapter for
  that.

See also: **Search**, **Templates**.
